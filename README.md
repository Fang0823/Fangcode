Data and Code for Thermal Aging of Natural Rubber
This repository provides supporting data and code for the manuscript:
An Exposure-Driven Dielectric Constitutive Model for Predicting Terahertz Responses of Thermally Aged Natural Rubber。
This study models the terahertz response of thermally aged natural rubber.
The repository currently contains selected analysis scripts and experimental data for one aging temperature. This partial release does not support reproduction of all results reported in the manuscript. Some scripts require additional data that are not yet included.
The complete dataset and accompanying analysis and plotting code will be made publicly available in this repository upon acceptance of the manuscript. Instructions for reproducing the results will also be provided.
